# Big Waves on California's Central Coast

**Author:** Johnny Peschong

## Research Question

How often does California's Central Coast get really big waves, how big do the biggest swells get, and what months do they usually happen in? I'm using historical wave data from NOAA ocean buoys off the Central Coast to count big-wave days, find the largest swells on record, and see which months and seasons produce them. As a surfer from this area, I want to back up what local surfers "know" about big-wave season with real data.
